# Project instructions

## UI platform scope

Relay is a desktop Web application. This applies to the entire project.

- Do not propose or implement mobile/tablet-specific designs or include mobile
  viewport/touch testing in acceptance unless the user explicitly changes scope.
- Existing responsive fallbacks may remain; they do not imply mobile support.
- Preserve desktop keyboard accessibility, visible focus, zoom support, and
  readable layouts when desktop windows are resized.
- Follow `docs/ui-interaction-spec.md` for shared light/dark themes, Tali / Guard
  family styling, component states, and desktop acceptance criteria.
